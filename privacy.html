Privacy

Your images never leave your device. Background removal runs entirely in your browser.

What happens to your images

  • Images you drop, choose or paste are processed locally by an AI model running in your browser (WebGPU or WebAssembly).
  • Images are never uploaded — not to us, not to GitHub, not to any other service.
  • Images and results are kept in memory only while the page is open. They are not stored on your device, and they are gone when you close or reload the page.
  • The downloaded PNG contains no metadata (no EXIF, no location) from the original photo.

What is downloaded

The page loads its own code, styles and the AI model (about 93 MB, once) from the same web address. The model is stored in your browser's cache storage so later visits load it from disk and the app also works offline. You can remove it at any time by clearing this site's data in your browser settings.

The page's Content Security Policy only allows network requests to its own address, so it cannot send data to any other server.

No accounts, no tracking

  • No signup, no account, no payment.
  • No analytics, no advertising, no tracking pixels, no third-party scripts or fonts.
  • No cookies. Apart from the cached app and model, only small technical settings (such as your colour theme) are kept in your browser's storage.

Hosting

The website is served as static files by GitHub Pages. Like any web server, GitHub receives technical request data (such as your IP address) when your browser loads the page's files; see the GitHub Privacy Statement. Your images are never part of these requests.

Open source

The complete source code is public, so all of this can be verified: GitHub repository. The AI model is BiRefNet (MIT License).

Datenschutz

Deine Bilder verlassen nie dein Gerät. Die Hintergrundentfernung läuft vollständig in deinem Browser.

Was mit deinen Bildern passiert

  • Bilder, die du hineinziehst, auswählst oder einfügst, werden lokal von einem KI-Modell in deinem Browser verarbeitet (WebGPU oder WebAssembly).
  • Bilder werden nie hochgeladen — nicht zu uns, nicht zu GitHub, zu keinem anderen Dienst.
  • Bilder und Ergebnisse liegen nur im Arbeitsspeicher, solange die Seite geöffnet ist. Sie werden nicht auf deinem Gerät gespeichert und sind nach dem Schließen oder Neuladen der Seite weg.
  • Das heruntergeladene PNG enthält keine Metadaten (kein EXIF, keinen Standort) aus dem Originalfoto.

Was geladen wird

Die Seite lädt ihren eigenen Code, die Gestaltung und das KI-Modell (ca. 93 MB, einmalig) von derselben Webadresse. Das Modell wird im Cache-Speicher deines Browsers abgelegt, damit spätere Besuche es von der Festplatte laden und die App auch offline funktioniert. Du kannst es jederzeit entfernen, indem du die Websitedaten in den Browsereinstellungen löschst.

Die Content Security Policy der Seite erlaubt Netzwerkanfragen nur an die eigene Adresse. Die Seite kann also keine Daten an andere Server senden.

Keine Konten, kein Tracking

  • Keine Anmeldung, kein Konto, keine Bezahlung.
  • Keine Analyse, keine Werbung, keine Tracking-Pixel, keine Skripte oder Schriften von Drittanbietern.
  • Keine Cookies. Neben der zwischengespeicherten App und dem Modell werden nur kleine technische Einstellungen (etwa dein Farbschema) im Browserspeicher abgelegt.

Hosting

Die Website wird als statische Dateien über GitHub Pages ausgeliefert. Wie jeder Webserver erhält GitHub dabei technische Verbindungsdaten (z. B. deine IP-Adresse), wenn dein Browser die Dateien der Seite lädt; siehe das GitHub Privacy Statement. Deine Bilder sind nie Teil dieser Anfragen.
